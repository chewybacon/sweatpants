# Caller-Authoritative Program Extension v1

**Status:** Reserved — pre-publication  
**Extension URI:** `https://github.com/chewybacon/sweatpants/blob/main/protocols/a2a/caller-authoritative-program/v1/spec.md`

This path reserves the versioned identifier for a future A2A extension that advertises caller-authoritative execution of pinned Sweatpants programs through a remote `ProgramDriver`.

This stub is not a normative protocol specification and does not activate or define interoperable behavior. Implementations **MUST NOT** advertise, request, or claim support for this extension URI until an approved normative specification replaces this pre-publication stub.

The v1 URI is reserved for immutable normative semantics once published. Breaking changes will use a new versioned URI.
